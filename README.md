GREENMOTION EV Website

A simple website built using HTML and CSS.

Files

index.html — Website structure and content.

style.css — Website styling and layout.

Run Locally

Keep both files in the same folder.

Open the folder in VS Code.

Open index.html.

Run it using the Live Server extension, or open index.html in your browser.

Note

Do not rename style.css unless you also update the stylesheet link in index.html.
